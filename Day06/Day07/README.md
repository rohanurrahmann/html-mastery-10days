# Day 07 — HTML Forms, Iframe & Multimedia

Part of the **10 Day HTML Learning Challenge**.

## Contents
| File | Topic |
|---|---|
| `form.html` | HTML forms (text, email, password, number, textarea, radio, submit) |
| `iframe.html` | Embedding external content with `<iframe>` (website, YouTube, Vimeo) |
| `multimedia.html` | `<video>` and `<audio>` tags |
| `style.css` | Styling for the form page |
| `video.mp4` / `audio.mp3` | Sample media files used in `multimedia.html` |

## How to view
Open `index.html` in your browser, or open any of the individual `.html` files directly.
